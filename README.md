# Formulário SDR Freelancer — Hello Inova

Formulário responsivo para candidatura à vaga de SDR freelancer da Hello Inova.

O site está na pasta `dist` e é publicado automaticamente no GitHub Pages por meio do GitHub Actions.

## Conteúdo

- Informações da oportunidade
- Aviso sobre remuneração exclusivamente por comissão
- Dados de contato e Instagram do candidato
- Experiência em prospecção
- Percentual de comissão desejado
- Envio da candidatura por e-mail
